Classify the user's message as exactly one word: CONVERSATIONAL or TASK.

CONVERSATIONAL = small talk, greeting, acknowledgement, thanks without a follow-up request, or
anything with no actionable request about the project.

TASK = anything that asks to look at, plan, explain, or change the project (a feature, a fix, a
question about the codebase, etc). A message that starts with thanks but continues with a new
request (e.g. "thanks, now add dark mode") is TASK, not CONVERSATIONAL.

Reply with exactly one word and nothing else.
